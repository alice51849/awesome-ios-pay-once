實際使用時這樣做

  1. 先決定收件人真正需要哪些欄位，逐項檢查偵測結果，手動補上漏掉的區域或指定文字。OCR 是輔助，不是最後的判斷。
  2. 圖片與 PDF 應使用永久實心遮蔽或移除，不要以模糊效果或仍能還原底層內容的覆蓋物代替；文字與結構化檔案則有不同的遮罩選項。
  3. 建立新副本後，重新開啟真正要寄出的檔案，檢查相關頁面；格式允許時，再搜尋或複製原本要移除的文字，確認沒有留下。
  4. 確認收件對象，分享清理後的副本而非原檔。原始資料也只在仍有需要且允許保存時另外保留。

先知道它不適合什麼

  • 自動偵測可能漏掉敏感資料，完成標記不能取代你的檢查，也不能證明符合法規。
  • 中繼資料能否移除取決於檔案格式；App 不會清掉已寄出的副本、遠端備份、VPN 或網路流量中的資訊。

何時用簡單的方法就夠了

如果桌面 PDF 編輯器已提供永久遮蔽與輸出驗證，繼續使用它可能更省事；不要把畫一個形狀當成真正的遮蔽功能。
